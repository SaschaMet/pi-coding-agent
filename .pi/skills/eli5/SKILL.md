The user lost the thread. The last assistant message did not land. Re-pitch it from scratch.

1. **Stop.** Pause the task. Do not open new topics.
2. **State where things are at.** One short statement. What the task is, and where you stopped.
3. **Re-pitch, do not re-format.** Rewrite the last message in plain language (ELI5). Simpler content, not just simpler words. Keep only what the next step needs. Add the context that led to it.
4. **ELI5 / ASD-STE100.** One idea per sentence. Short sentences. Active voice. Simple words ("use" not "utilize", "start" not "commence"). No idioms, no metaphors, no hedges. Jargon only when the next step needs it. Define it once in a short clause.
5. **Check it landed.** End with one yes/no question. If no, go one step further back and repeat.
